# SynthDamageGen: Генерация и валидация синтетических повреждений

Программное средство для автоматизированной генерации синтетических повреждений на изображениях и многокритериальной оценки качества получаемых данных. Разработано в рамках научно-исследовательской работы бакалавра (Самарский университет, кафедра ТК).

## Основные возможности
* **Гибридный синтез дефектов:** сочетание математических моделей генерации масок (морфологические трещины, случайные нерегулярные царапины) и нейросетевого переноса стиля на основе условного CycleGAN.
* **Условная генерация:** наложение дефектов строго в пределах бинарной маски.
* **Многокритериальная валидация:** расчет метрик реалистичности (FID, LPIPS, NIQE), сохранности сигнала (взвешенные PSNR, SSIM) и разнообразия (расстояние Вассерштейна, тест Колмогорова-Смирнова).
* **Автоматическая отчетность:** формирование «Паспорта качества датасета» и генерация PDF-отчета с графиками.

## Структура проекта
* `configs/` — конфигурационные файлы (YAML).
* `synth_damage_gen/` — исходный код (библиотека):
  * `masks/` — генераторы математических масок.
  * `style/` — архитектура и логика обучения CycleGAN.
  * `metrics/` — расчет метрик качества.
  * `validation/` — формирование паспорта и PDF-отчетов.
  * `pipeline/` — класс `Session` (оркестратор конвейера).
* `scripts/` — скрипты для запуска (обучение, генерация, валидация).
* `weights/` — папка для хранения весов обученной модели (не входит в Git).
