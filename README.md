# SynthDamageGen: Генерация и валидация синтетических повреждений

![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue)
![PyTorch 2.x](https://img.shields.io/badge/PyTorch-2.x-ee4c2c)
![License](https://img.shields.io/badge/License-MIT-green)

**SynthDamageGen** — это программное средство для автоматизированной генерации синтетических повреждений на изображениях и их многокритериальной оценки. Проект разработан в рамках научно-исследовательской работы бакалавра (Самарский национальный исследовательский университет им. академика С.П. Королева, кафедра технической кибернетики).

Система решает проблему нехватки парных данных («поврежденное фото — эталон») для обучения моделей реставрации старых фотографий.

## 🚀 Основные возможности

* **Гибридный синтез дефектов:** сочетание математических моделей генерации масок (нерегулярные царапины, морфологические трещины) и нейросетевого переноса стиля на основе условного **CycleGAN**.
* **Условная генерация:** наложение дефектов происходит строго в пределах заданной бинарной маски, не затрагивая чистый фон.
* **Многокритериальная валидация:**
  * *Сохранность (Preservation):* взвешенные PSNR и SSIM (считаются только по фону).
  * *Реалистичность (Realism):* LPIPS, NIQE.
  * *Разнообразие (Diversity):* расстояние Вассерштейна (W1_Area) и стандартное отклонение площади масок (Std_Area).
* **Автоматическая отчетность:** формирование «Паспорта качества датасета» и генерация PDF-отчета с графиками и вердиктом о пригодности данных.

## 🏗 Архитектура конвейера

Работа системы разделена на два этапа:
1. **Обучение:** Выполняется в облачной среде (например, Google Colab с GPU) на двух непарных доменах (чистые фото и реальные старые фото). Результат — веса модели (`weights.pth`).
2. **Генерация и Валидация:** Выполняется локально на CPU. Система генерирует маски, накладывает дефекты, считает метрики и выдает итоговый PDF-отчет.
