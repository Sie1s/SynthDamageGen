# SynthDamageGen: Генерация и валидация синтетических повреждений

![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue)
![PyTorch 2.x](https://img.shields.io/badge/PyTorch-2.x-ee4c2c)
![License](https://img.shields.io/badge/License-MIT-green)

**SynthDamageGen** — это программное средство для автоматизированной генерации синтетических повреждений на изображениях и их многокритериальной оценки. Проект разработан в рамках научно-исследовательской работы бакалавра (Самарский национальный исследовательский университет им. академика С.П. Королева, кафедра технической кибернетики).

Система решает проблему нехватки парных данных («поврежденное фото — эталон») для обучения моделей реставрации старых фотографий.

## 🚀 Основные возможности

* **Гибридный синтез дефектов:** сочетание математических моделей генерации масок (нерегулярные царапины, морфологические трещины) и нейросетевого переноса стиля на основе условного **CycleGAN**.
* **Условная генерация:** наложение дефектов происходит строго в пределах заданной бинарной маски, не затрагивая чистый фон.
* **Многокритериальная валидация:**
  * *Сохранность (Preservation):* взвешенные PSNR и SSIM (считаются только по фону).
  * *Реалистичность (Realism):* LPIPS, NIQE.
  * *Разнообразие (Diversity):* расстояние Вассерштейна (W1_Area) и стандартное отклонение площади масок (Std_Area).
* **Автоматическая отчетность:** формирование «Паспорта качества датасета» и генерация PDF-отчета с графиками и вердиктом о пригодности данных.

## 🏗 Архитектура конвейера

Работа системы разделена на два этапа:
1. **Обучение (Training):** Выполняется в облачной среде (например, Google Colab с GPU) на двух непарных доменах (чистые фото и реальные старые фото). Результат — веса модели (`weights.pth`).
2. **Генерация и Валидация (Inference & Validation):** Выполняется локально на CPU. Система генерирует маски, накладывает дефекты, считает метрики и выдает итоговый PDF-отчет.

## ⚙️ Установка

Для запуска проекта потребуется Python 3.10 или выше. Рекомендуется использовать виртуальное окружение.

### Шаг 1. Клонируйте репозиторий:

```bash
git clone https://github.com/Sie1s/SynthDamageGen.git
cd SynthDamageGen
```

### Шаг 2. Создайте и активируйте виртуальное окружение:

**Для Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\activate
```

**Для Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 3. Установите все необходимые зависимости:

```bash
pip install -r requirements.txt
```

## 🛠 Использование

### 1. Подготовка данных

Создайте в корне проекта папку `data` со следующим содержимым:

- `data/clean_dataset/` — поместите сюда чистые, качественные фотографии (например, из датасета CelebA).
- `data/old_photos/` — поместите сюда реальные старые фотографии с дефектами (необходимы только для обучения).
- `weights/` — создайте эту папку и положите в неё файл с весами обученной модели `cyclegan_mask.pth`.

### 2. Запуск полного пайплайна

Для генерации датасета и его автоматической валидации одной командой выполните:

```bash
python scripts/run_pipeline.py --input_dir data/clean_dataset --max_images 50
```

- `--input_dir` — путь к папке с чистыми фото.
- `--max_images` — количество изображений, которое нужно обработать (по умолчанию 100).

После завершения работы в консоли отобразится таблица с метриками, а в папке `reports/` появится файл `session_report.pdf` с «Паспортом качества» датасета.

### 3. Обучение модели (опционально)

Обучение CycleGAN требует значительных вычислительных ресурсов и рекомендуется к запуску в облаке (например, в Google Colab):

```bash
python scripts/train_cyclegan.py --data_dir /path/to/clean --damaged_dir /path/to/old --epochs 30 --batch_size 4
```

## 📊 Метрики и Паспорт качества датасета

В основе валидации лежит объективная оценка трех аспектов, которые автоматически рассчитываются и сравниваются с пороговыми значениями из `configs/default.yaml`:

1. **Сохранность сигнала (Preservation):**
   - PSNR (Peak Signal-to-Noise Ratio) и SSIM (Structural Similarity).
   - *Особенность:* Рассчитываются только для пикселей фона (где маска равна 0). Это позволяет оценить, насколько бережно генератор обошелся с оригиналом за пределами дефекта.

2. **Реалистичность (Realism):**
   - LPIPS (Learned Perceptual Image Patch Similarity) — оценивает перцептивное сходство.
   - NIQE (Natural Image Quality Evaluator) — безреферентная оценка «естественности» изображения.

3. **Разнообразие и пространственная точность (Diversity):**
   - W1_Area (Расстояние Вассерштейна) — сравнивает площадь исходных масок и площадь пикселей, которые нейросеть фактически изменила. Показывает, насколько точно сеть следует заданной маске.
   - Std_Area (Стандартное отклонение площади) — оценивает внутреннее разнообразие генератора (создает ли он дефекты разных размеров).

**Паспорт качества:** Результаты всех измерений агрегируются. Если хотя бы одна метрика не проходит установленный порог, общий вердикт выставляется как «НЕ ПРИГОДЕН». Итоговый PDF-отчет содержит графики, таблицу метрик и текстовое заключение.
